# Elimika Foundation

Elimika is the Swizzy Industries education platform. It focuses on
curriculum-aligned immersive learning, STEM, and vocational training for
schools and institutions across Kenya.

Production: [elimika.swizzyindustries.com](https://elimika.swizzyindustries.com)

## Local development

This app is part of the Bun workspace. Install dependencies once from the
repository root:

```bash
bun install
```

Start just Elimika from this directory:

```bash
bun run dev
```

Open [http://localhost:4201](http://localhost:4201). To run all six websites
together, use `bun run dev` from the repository root instead. Stop the server
with `Ctrl+C`.

The app's `.env.development` and `.env.production` configure
`NEXT_PUBLIC_HOST` and `NEXT_PUBLIC_PROTOCOL`, which are used to build links
between the product websites. Keep local environment values out of source
control and do not copy production values into development configuration.

## Useful commands

Run these from this directory:

| Command         | Purpose                                   |
| --------------- | ----------------------------------------- |
| `bun run dev`   | Start the development server on port 4201 |
| `bun run build` | Create a production build                 |
| `bun run start` | Serve the production build on port 4201   |
| `bun run lint`  | Run ESLint                                |

The root workspace also provides `bun run build`, `bun run lint`,
`bun run typecheck`, and `bun run format` for the monorepo. `typecheck` and
`format` are configured only for workspaces that define those scripts.

## Where to work

- `app/page.tsx` is the homepage entry point. Homepage sections are composed
  in `components/homepage/`.
- `components/site-header.tsx`, `components/mobile-navigation.tsx`, and
  `components/site-footer.tsx` implement the shared site chrome.
- `lib/site-navigation.ts` contains the navigation and menu content.
- `lib/construction-routes.ts` describes recognized routes and supplies the
  sitemap route list. `lib/site-navigation/pages.ts` contains designed-page
  definitions.
- `app/[...slug]/page.tsx` resolves non-homepage routes and their metadata.
  Add navigation/page data using the existing route helpers so links, page
  titles, and the sitemap remain aligned.
- `app/layout.tsx` owns the brand theme, providers, global styles, and site
  metadata. Shared UI components and brand tokens live in `packages/ui/`.

## Brand, assets, and SEO

The root layout selects the `elimika` brand with `data-brand="elimika"`.
Shared theme variables are defined in
`packages/ui/src/styles/brands/elimika.css`; avoid duplicating those palette
values in app CSS. The header uses the icon and wordmark from
`public/logos/`.

The app's `public/icons/` contains its ICO favicon and Apple touch icons.
`public/images/og-image.png` is the social-sharing banner used by Open Graph,
WhatsApp, and other link-preview services. Site-wide SEO defaults are shared
through `packages/ui/src/lib/seo.ts`; page-specific metadata is generated by
the dynamic route. `app/robots.ts` and `app/sitemap.ts` serve `/robots.txt` and
`/sitemap.xml`.

## Before shipping

From this directory, run:

```bash
bun run lint
bun run build
```

Deploy this workspace as its own Next.js app, with the production domain above
and the production host/protocol environment configuration available at build
and runtime.
